# YOLOv26n 装甲板推理与关键点可视化

## 一、项目功能
本项目使用 YOLOv26n 模型对自行拍摄的装甲板视频进行推理，实现了：
1. 读取视频并逐帧推理。
2. 绘制检测框、类别、置信度。
3. 绘制装甲板的4个关键点（来自模型预测，非检测框角点）。
4. 保存处理后的视频。

## 二、运行环境
*   **Python版本**：3.11
*   **主要依赖**：ultralytics, opencv-python, numpy (见 requirements.txt)
*   **运行设备**：使用 GPU (NVIDIA RTX 5060) 进行推理（如果最终是用 CPU 跑的，就改成“使用 CPU 进行推理”）。

## 三、模型权重准备
模型权重 `best.pt` 未上传至 Git 历史（已通过 .gitignore 排除）。
**运行前，请将 `best.pt` 放在项目根目录下。**

## 四、依赖安装与运行命令
1. 安装依赖：
   `pip install -r requirements.txt`
2. 运行推理（需要提前准备好测试视频 `test.mp4` 并放在根目录）：
   `python inference.py`
3. 结果保存位置：
   推理后的视频保存为根目录下的 `result.mp4`。

## 五、视频拍摄说明
*   拍摄地点：水建学院 D414 实验室。
*   时长：约 【13】 秒。
*   场景说明：手持设备横屏拍摄，包含清晰的装甲板，适当改变了距离和角度。
