# 相机标定、PnP 位姿解算与卡尔曼滤波

## 1. 作业流程

```text
相机采集
→ YOLO 装甲板检测
→ 4 个角点
→ 角点排序
→ solvePnP
→ 三维位置 XYZ + 姿态
→ 卡尔曼滤波
→ 位置/速度估计与短时预测
```

## 2. 文件说明

```text
calibration/calibrate_camera.py   棋盘格标定
calibration/images/                标定图片目录
configs/camera.yaml                内参、畸变、装甲板尺寸
detect/armor_pose.py               角点排序、PnP、卡尔曼
main_pose.py                       完整实时流程
tests/test_pose_pipeline.py        离线测试
```

## 3. 相机标定

### 3.1 准备棋盘格

使用 **9×6 内角点**的棋盘格，方格边长 **25 mm**。  
拍摄 15～25 张不同角度、不同位置的图片，放到：

```text
calibration/images/
```

### 3.2 运行标定

```bash
cd ~/projects/industrial-camera-armor
./.venv/bin/python calibration/calibrate_camera.py \
  --images calibration/images \
  --cols 9 --rows 6 --square-size 0.025 \
  --output configs/camera.yaml
```

输出：

```text
RMS: ...
Mean reprojection error: ...
camera_matrix: ...
dist_coeffs: ...
```

`configs/camera.yaml` 会保存：

- `camera_matrix`：内参矩阵
- `dist_coeffs`：畸变系数
- `image_width` / `image_height`
- `armor.width_m` / `armor.height_m`
- `calibrated: true`

> 现在仓库里的 `configs/camera.yaml` 是**占位内参**，`calibrated: false`。  
> 不标定也能跑通流程，但 XYZ 和距离不准确。

## 4. 装甲板角点

YOLO pose 模型输出 **4 个关键点**：

```text
kpt_shape = [4, 2]
```

模型自己的顺序可能是：

```text
左上 → 左下 → 右下 → 右上
```

代码里的 `order_corners()` 不依赖模型顺序，会自动排成：

```text
TL → TR → BR → BL
```

对应三维物点：

```text
(-w/2, -h/2, 0)
( w/2, -h/2, 0)
( w/2,  h/2, 0)
(-w/2,  h/2, 0)
```

`w` 和 `h` 是装甲板实际宽度和高度，单位米。  
默认按大装甲板 **225 mm × 55 mm**，如果你的板子不同，改：

```yaml
armor:
  width_m: 0.225
  height_m: 0.055
```

或者命令行覆盖：

```bash
--armor-width 0.135 --armor-height 0.055
```

## 5. PnP

核心调用：

```python
ok, rvec, tvec = cv2.solvePnP(
    object_points,
    image_points,
    camera_matrix,
    dist_coeffs,
    flags=cv2.SOLVEPNP_IPPE,
)
```

输出：

- `rvec`：旋转向量
- `tvec`：平移向量，单位米
- `distance_m = ||tvec||`：相机到装甲板中心的距离
- `euler_deg`：yaw / pitch / roll
- `reprojection_error_px`：重投影误差，用来判断角点/PnP 是否可靠

屏幕上会画：

- 装甲板检测框
- 四个角点
- 重排后的四边形
- 三维坐标轴
- XYZ、距离、姿态角、重投影误差

## 6. 卡尔曼滤波

状态向量：

```text
[x, y, z, vx, vy, vz]
```

测量向量：

```text
[x, y, z]
```

模型：

```text
x(k+1) = x(k) + vx(k) * dt
y(k+1) = y(k) + vy(k) * dt
z(k+1) = z(k) + vz(k) * dt
v(k+1) = v(k)
```

使用 OpenCV `KalmanFilter(6, 3)`。

每帧：

1. `predict()` 得到先验预测；
2. `correct(tvec)` 用 PnP 测量更新；
3. 输出滤波后的位置、速度；
4. 用 `filtered + velocity * horizon` 做短时预测。

屏幕会同时显示：

```text
XYZ(m)        原始 PnP 测量
KF            滤波后的位置
KF pred       卡尔曼先验预测
future +0.2s  0.2 秒后的预测位置
v(m/s)        估计速度
```

## 10. 注意事项

1. **必须先标定**，否则 XYZ 和距离只是近似值；
2. 装甲板宽度/高度必须用实际尺寸，否则距离会按比例偏差；
3. 模型关键点抖动会直接传到 PnP，卡尔曼只能减小抖动，不能修复错误角点；
4. 目前只跟踪置信度最高的一个装甲板；多目标可以扩展为按类别/ID 维护多个卡尔曼滤波器；
5. 重投影误差大于 3～5 px 时，建议丢弃该帧 PnP。
