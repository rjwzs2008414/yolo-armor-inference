# 小版本提交说明

## 1. 为什么做小版本

实验室装甲板 LED 灯条损坏，无法在作业要求的 500/1000/3000 μs 短曝光下获得正常发光装甲板画面。为了保证仍然能提交一个完整、可运行、可解释的版本，采用“短曝光异常组 + 长曝光补偿组”的方案。

## 3. 关键结果

- 相机：Hikrobot MV-CA016-10UC，序列号 00L28498186，固件 V1.6.3。
- 短曝光异常组：500/1000/3000 μs 平均灰度 0.017/0.235/1.396，YOLO 检测数均为 0。
- 补偿组：30 ms / 12 dB / BayerRG8 / Gamma 0.7 + unsharp + bloom，1 号装甲板检测置信度 **0.81**。
- 格式：BayerRG8 约 70.4 FPS / CPU 161.9%；BGR8 约 70.4 FPS / CPU 46.9%。

## 4. 运行方法

```bash
cd ~/industrial-camera-armor
./run.sh main.py --model models/best.pt \
  --exposure 30000 --gain 12 --format BayerRG8 \
  --enhance --imgsz 960 --conf 0.2 \
  --headless --seconds 15 \
  --output results/live_demo_enhance.mp4
```

## 6. 已知限制

1. 装甲板灯条损坏，短曝光图像接近全黑；
2. 补偿组使用 30 ms 长曝光，运动目标会产生明显拖影；
3. 真实运动目标序列未拍，使用仿真模糊补充；
4. CPU 推理约 3～7 FPS，未使用 CUDA。
